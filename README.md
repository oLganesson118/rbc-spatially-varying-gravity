# Rayleigh-Bénard Convection with Spatially Varying Gravity as a Simplified Model of Convection in Plasma

This repository contains the work from the project **“Rayleigh-Bénard Convection with Spatially Varying Gravity as a Simplified Model of Convection in Plasma”**, conducted by **Olga Borbély** under the supervision of **XX**.

## Project

The project began as a **KTH Digital Futures Summer School 2026** project, conducted at **Nordita – The Nordic Institute for Theoretical Physics**. Following the conclusion of the KTH Digital Futures Summer School 2026, the project will continue at Nordita.

The project investigates Rayleigh-Bénard convection with a spatially varying gravitational field as a simplified model for convection in plasma.
